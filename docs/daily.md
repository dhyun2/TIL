## 배운 점

브라우저는 저장된 응답이 만료되면 ETag를 담아 서버에 다시 확인할 수 있다.
서버가 `304 Not Modified`로 응답하면 이전에 저장한 본문을 재사용한다.

## 직접 확인한 내용

개발자 도구의 Network 탭에서 `If-None-Match` 요청과 304 응답을 확인했다.
